# Backend sistema Guia e turismo

Desenvolver o backend de um sistema de Guia de turismo que será consumido em um app em Flutter (App Flutter já existe, não deve ser criado/desenvolvido).
Os sistema deve ter CRUD para usuarios, lugares, galeria (de fotos de lugares), favoritos (lugares favoritos) e categoria (de lugares).
O sistema backend deve ser em Node.js com boas práticas de segurança, código limpo, e reaproveitamento de código quando possível. 
AS variáveis e funções devem ser escritas em português brasileiro, com texto mínimo (resumindo sempre que possível. Ex.: ao invés de: listagemDeProdutos usar: ListarProdutos).

Arquitetura deve ser dividida em Controllers, Services, Models, Middlewares e Routes.

Use as tecnologias Node.js, TypeScript, Prisma ORM, Swagger para documentar e Banco será no Supabase. O projeto será publicado no Render inicialmente.

Use todos recursos de segurança contra ataques hackers e tentativas de invsão vindas pelo frontend ou por requisições diretas à API.

Crie por partes, terminando uma parte informe que já terminou para seguir para a próxima.

É um projeto didádico que será compartilhado com alunos do curso Técnico em desenvolvimento de sistemas. Use linguagem simples e impessoal sempre que comentar o código e explique resumidamente o conceito e não apenas a aplicação no contexto do projeto.
